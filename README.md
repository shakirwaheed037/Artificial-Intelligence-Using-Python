Artificial Intelligence Using Python 🤖
A collection of practical coding exercises completed as part of the
Artificial Intelligence Using Python course offered by
Skills.pk. This repository brings together four exercises focused on
Python programming, data analysis, machine learning, deep learning, and
natural language processing.

The goal of this repository is to document hands-on learning and
demonstrate how Python-based tools and models can be used to explore
data, prepare datasets, train classification models, evaluate results,
and process text for AI applications.
📚 Course Overview
Throughout these exercises, the work progresses from core Python
concepts to applied AI workflows:
- Python loops, conditional statements, and object-oriented
  programming (OOP)
- Creating and manipulating arrays with NumPy
- Exploring and preparing datasets with Pandas
- Building and evaluating an SVC classification model
- Text preprocessing and Natural Language Processing (NLP)
- Developing deep learning classification models with TensorFlow/Keras
- Evaluating models with metrics and visualizations
- Preparing text with Hugging Face Transformers tokenization
🧪 Exercises and Learning Outcomes
Exercise 1: Python Fundamentals, NumPy, and OOP
Learning outcomes: - Apply loops and conditional statements to solve
simple programming problems. - Create and manipulate NumPy arrays. -
Implement basic Object-Oriented Programming (OOP) concepts in Python.
Exercise 2: Dataset Exploration and SVC Classification
Learning outcomes: - Load and explore a real-world dataset using
Pandas, including its structure, variables, summary statistics, and data
distributions. - Clean and prepare data for machine learning by handling
missing values, identifying relevant features, and preparing target and
independent variables. - Build, evaluate, and analyze an SVC
classification model using suitable performance metrics and
visualizations to understand passenger survival patterns.
Exercise 3: Text Processing and Deep Learning for Toxic Comment Classification
Learning outcomes: - Load and explore a text dataset with Pandas by
examining records, dimensions, column names, data types, missing values,
and class distribution. - Preprocess textual comments by cleaning text,
separating input text from the target variable, encoding labels, and
splitting data into training and testing sets. - Apply NLP preprocessing
with tokenization and sequence padding to prepare text for deep
learning. - Build, train, and evaluate a deep learning model (ANN, CNN,
or LSTM) using TensorFlow/Keras for multi-class toxic comment
classification. - Visualize model performance with accuracy and loss
curves, use a confusion matrix, and test the trained model on new
comments.
Exercise 4: CNN/RNN Classification and Transformer Tokenization
Learning outcomes: - Load, explore, and preprocess a categorical
dataset by converting categorical features into a numerical format
suitable for deep learning. - Design and implement CNN and RNN models
using TensorFlow/Keras for classification on the prepared dataset. -
Train deep learning models with different batch sizes, epochs, and
optimizers, and observe their training performance. - Generate
predictions and evaluate classification models using accuracy, confusion
matrices, classification reports, and other relevant measures. - Compare
CNN and RNN performance using evaluation results and visualizations. -
Apply text tokenization with the Hugging Face Transformers library to
prepare text for NLP and Generative AI applications.

▶️ How to Run the Code
1. Clone or download this repository.
2. Open the relevant exercise folder in Visual Studio Code or another
   Python editor.
3. Review that exercise's documentation and code.
4. Install the dependencies required by the selected exercise.
5. Run the relevant Python file or notebook.
Example setup:
python -m venv .venv
Activate the virtual environment, then install the packages required by
the exercise. Depending on the code, these may include:
pip install numpy pandas scikit-learn matplotlib seaborn tensorflow transformers
Note: Install only the packages needed for the specific exercise.
Some exercises may require additional setup or dataset files. Check the
exercise documentation before running the code.
