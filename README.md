# Artificial Intelligence Using Python 🤖

A collection of practical coding exercises completed as part of the **Artificial Intelligence Using Python** course offered by **Skills.pk**. This repository contains four exercises covering Python programming, data analysis, machine learning, deep learning, and Natural Language Processing (NLP).

The main objective of this repository is to demonstrate practical learning through Python-based coding tasks, dataset exploration, classification models, deep learning techniques, and text processing for AI applications.

---

## 📚 Course Overview

Throughout these exercises, the learning journey progresses from Python fundamentals to practical Artificial Intelligence workflows.

Key areas covered include:

- Python programming fundamentals and Object-Oriented Programming (OOP).
- Array creation and manipulation using NumPy.
- Dataset exploration and preprocessing using Pandas.
- Machine Learning classification using Support Vector Classifier (SVC).
- Natural Language Processing (NLP) and text preprocessing.
- Deep Learning model development using TensorFlow and Keras.
- CNN and RNN model implementation and comparison.
- Model evaluation using performance metrics and visualizations.
- Text tokenization using Hugging Face Transformers.
- Foundations for NLP and Generative AI applications.

---

## 🧪 Exercises and Learning Outcomes

### 🔹 Exercise 1: Python Fundamentals, NumPy, and OOP

**Learning Outcomes:**

- Apply loops and conditional statements to solve simple programming problems.
- Create and manipulate NumPy arrays.
- Implement basic Object-Oriented Programming (OOP) concepts in Python.

**Key Concepts:** Python fundamentals, control flow, NumPy arrays, and OOP.

### 🔹 Exercise 2: Data Analysis and SVC Classification

**Learning Outcomes:**

- Load and explore a real-world dataset using Pandas by examining its structure, variables, summary statistics, and data distributions.
- Clean and prepare data for machine learning by handling missing values, identifying relevant features, and preparing target and independent variables.
- Build, evaluate, and analyze an SVC classification model using appropriate performance metrics and visualizations to understand passenger survival patterns.

**Key Concepts:** Data exploration, data cleaning, feature selection, SVC classification, model evaluation, and data visualization.

### 🔹 Exercise 3: NLP and Deep Learning for Toxic Comment Classification

**Learning Outcomes:**

- Load and explore a text dataset using Pandas by examining records, dimensions, column names, data types, missing values, and class distribution.
- Preprocess textual comments by cleaning text, separating input text from the target variable, encoding labels, and splitting data into training and testing sets.
- Apply NLP preprocessing using tokenization and sequence padding to convert text into a format suitable for deep learning.
- Build, train, and evaluate a deep learning model (ANN, CNN, or LSTM) using TensorFlow/Keras for multi-class toxic comment classification.
- Visualize model performance using accuracy and loss curves, analyze a confusion matrix, and test the trained model on new comments.

**Key Concepts:** Text preprocessing, tokenization, sequence padding, ANN, CNN, LSTM, TensorFlow/Keras, and multi-class text classification.

### 🔹 Exercise 4: CNN/RNN Classification and Transformer Tokenization

**Learning Outcomes:**

- Load, explore, and preprocess a categorical dataset by converting categorical features into a numerical format suitable for deep learning.
- Design and implement CNN and RNN models using TensorFlow/Keras for classification.
- Train deep learning models using different batch sizes, epochs, and optimizers to observe training performance.
- Generate predictions and evaluate classification models using accuracy, confusion matrices, classification reports, and other relevant performance measures.
- Compare CNN and RNN model performance using evaluation results and visualizations.
- Apply text tokenization using the Hugging Face Transformers library to prepare text for NLP and Generative AI applications.

**Key Concepts:** Categorical data preprocessing, CNN, RNN, model training, classification metrics, model comparison, and Transformer tokenization.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/artificial-intelligence-using-python.git
```

### 2. Navigate to the Project Directory

```bash
cd artificial-intelligence-using-python
```

### 3. Create a Virtual Environment (Recommended)

```bash
python -m venv .venv
```

Activate the environment on Windows:

```bash
.venv\Scripts\activate
```

### 4. Install Required Libraries

Install the dependencies required by the specific exercise. Common packages may include:

```bash
pip install numpy pandas scikit-learn matplotlib seaborn tensorflow transformers
```

### 5. Run the Code

Open the relevant exercise folder in Visual Studio Code, review its documentation, ensure the required dataset is available, and run the appropriate Python file or notebook.

**Note:** Not every exercise requires every package listed above. Check the individual exercise documentation for its exact dependencies and dataset requirements.
